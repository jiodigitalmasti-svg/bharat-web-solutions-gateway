Self-Hosted Server Installer

Setup and host your secure multi-channel messaging API server under your private primary domain name inside any Shared cPanel or VPS environment.

1Download Deployment Package

Grab the complete runtime binary repository. It contains pre-bundled Node connection wrappers and responsive dashboard front-end files.

2Upload to cPanel File Manager

Log into your primary host cPanel client panel. Open the File Manager utility and navigate inside the public_html/ root index directory or configure a separate subdomain (e.g., api.yourdomain.com).

[Action] Upload -> Select "gateway_bws_v3.2.zip" -> Right Click -> Extract All

3Configure Node.js Application Manager

Search for Setup Node.js App inside cPanel search options to run your persistent WebSocket background process.

  • ⚙️ Node Version: Select 18.x or newer LTS
  • ⚙️ Application Startup File: server.js
  • ⚙️ Application URL: Select your desired subdomain URL

4Run Automated Dependency Install

Click the button below to simulate environment verification and dependency installation for client socket protocol elements.

5Setup Webhook and Environment File

Adjust the database connection configuration by modifying the environment parameter file.

PORT=3000
DATABASE_URL=mongodb://your_user:your_password@localhost:27017/bws_gateway
WEBHOOK_URL=https://yourdomain.com/incoming-webhook
